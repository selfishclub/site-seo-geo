# 측정 약속

**왜**: 효과는 며칠~몇 주 뒤에 나온다. 같은 질문으로 전후를 비교해야 변화가 보인다.

## 질문 3개 만들기
- **내 이름 · 가게 이름이 들어가지 않은 질문**으로 만든다. 이름을 넣으면 당연히 나온다.
- 손님이 실제로 할 말로 쓴다. 지역 · 대상 · 하는 일을 넣는다.
  - 예: 「강남에서 소상공인 AI 마케팅 교육 추천해 줘」
  - 예: 「제주 애월 아이 동반 브런치 카페 어디가 좋아?」
  - 예: 「프리랜서 디자이너 포트폴리오 사이트 잘 만든 사람 알려 줘」
- 사용자에게 「손님이 나를 찾을 때 AI에게 뭐라고 물어볼까요?」라고 묻고, 답을 다듬어 3개로 만든다.

## measure.json
```json
{ "questions": ["…", "…", "…"], "due": "2026-11-28" }
```
- `due`: 오늘부터 1주 뒤.
- 오늘 바로 한 번 물어본 결과를 「전」으로 기록해 두면 좋다. 사용자가 직접 물어보고 결과를 말해 주면 리포트 ④ 탭 표에 적는다.
